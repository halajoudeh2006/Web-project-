# AI Usage Declaration

We used AI tools (ChatGPT and Gemini) to help us with a few parts of this project when we got stuck:

## 1. CSS and Design
* **What we used it for:** Improving the CSS styling to make the website look cleaner and more modern.
* **The problem we had:** The movie cards were overlapping on smaller screens and the page had horizontal scrolling on mobile. AI helped us fix the CSS grid and spacing so it looks good on both laptop and phone.

## 2. Movie Mock Data
* **What we used it for:** Creating the list of 30 movies in our data file.
* **The problem we had:** Writing 30 movies by hand with titles, categories, ratings, and years took too much time and caused syntax errors. AI generated the JavaScript array for us quickly.

## 3. JavaScript Search and Sort
* **What we used it for:** Fixing bugs in the JavaScript code for searching and sorting.
* **The problem we had:** At first, the search bar and the sort dropdown didn't work together properly—when we sorted the movies, the search filter reset. AI helped us combine `filter()` and `sort()` correctly in our React component.
